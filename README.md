## Deploy en Vercel (2 minutos)

1. Subí esta carpeta a un repo nuevo en GitHub
2. En vercel.com → **New Project** → importar el repo
3. Framework Preset: **Other** · Build Command: vacío · Output Directory: vacío
4. Deploy

- Torre Jacaranda 41 m² (USD 105.000) — alquilado
- Av. Perón divisible 42 m² (USD 110.000) — sin cochera
